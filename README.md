# Student Performance and Study Habits
## Project Description

This project aims to analyze student performance and study habits using data mining techniques. By leveraging behavioral and academic attributes such as study time, attendance, sleep hours, and previous grades, the project applies classification techniques to categorize students based on their final academic performance.
In addition, clustering methods are utilized to group students with similar study routines and characteristics. By combining these approaches, the project uncovers patterns in student behavior and performance, providing valuable insights into different student profiles and study habits.


## Project Motivation

We chose this topic because understanding the relationship between study habits and academic performance is important for understanding educational outcomes. Analyzing these factors helps identify patterns that may be related to a student's academic performance.
By applying classification and clustering techniques, this project aims to discover distinct student profiles and better understand patterns in academic performance and study habits. This serves as a practical application of data mining in the educational domain and demonstrates how data-driven analysis can provide meaningful insights into student behavior and performance.
